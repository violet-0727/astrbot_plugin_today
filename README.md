# 她自己的今天

独立的插件，不依赖也不修改任何其它插件。

## 为什么需要它

之前她的所有状态都是「内部的数字」——心情、耐心、体力、好感。没有一件**发生在她身上的事**。

人会说「今天下雨」「数学小测没考好」「阳台那盆月季开了」——这些事跟对面的人无关，是她自己的日子。而那时候的花花，所有输出都指向对话里的人，像一个永远在等指令的客服。

这个插件就是给她一条**不围绕你转的时间线**。

## 怎么工作

**1. 按星期几挑池子**

工作日的事件偏学校（早读、食堂、体育课、晚自习），周末偏家里（浇花、画画、看番、游戏）。

**2. 事件之间带因果**

每天会抽一条「链」，链里的步骤是有前因后果的：

```
早上起晚了，差点没赶上第一节课
没顾上吃早饭，第二节课就开始饿
中午吃得特别急，下午一直有点撑 → 还挂着：晚饭想清淡一点
```

不是四条互相无关的随机事件，而是一天。

**3. 跨天连续**

- **长线**：阳台那盆月季会一天天开（花苞 → 开了一朵 → 开了三朵 → 谢了）；月考会一天天近（还没复习 → 翻了课本 → 做了两套卷子）
- **挂起的事**：昨天没做完的事，今天还在「还挂着的事」里，标着「昨天起」

**4. 每件事带影响**

```
下午 体育课跑了两圈，腿有点软
这件事让你现在有点累，说话会跟着变一点
```

不用跨插件通信，模型读到这句就会把「累」体现在语气里。

**5. 什么时候提**

- 每轮 15% 概率，两次之间至少 60 分钟（都可配置）
- 被问「在干嘛 / 今天怎么样 / 忙什么」→ **必定想起来**
- 每件只提一次，提过打勾；挂起的事划掉就消失

## 面板

配色和「她自己的笔记本 / 小回忆 / 情绪」三块保持一致（蓝白卡片），换来的是四个面板看起来是一套东西。

- **今天的事**：卡片，带时段、「让你现在怎样」、提过没提过
- **还挂着的事**：可以逐条划掉
- **跨天的长线**：月季和月考的进度条
- **最近七天**：提过的正常显示，没提的淡色

## 命令

| 命令 | 作用 |
|---|---|
| `/今天` | 看今天的事和状态 |
| `/今天 换` | 换一批 |
| `/今天 加 阳台的风很大` | 添一件 |

## 接口

| 路径 | 说明 |
|---|---|
| `GET /today` | 今天的 + 最近七天 |
| `POST /reroll` | 换一批 |
| `POST /add` | 添一件 |
| `POST /said` | 标记已提 |

## 数据

`data/plugin_data/astrbot_plugin_today/today.json`，只保留最近 14 天，删掉即可重建。

## 和别的插件怎么分工

| 插件 | 管什么 |
|---|---|
| 她自己的今天（本插件） | 她今天发生了什么 |
| 她自己的情绪 | 她心情怎么样 |
| 她自己的小回忆 | 她和谁发生过什么 |
| livelystate | 身体状态 |
