# 她自己的今天

独立的插件，不依赖也不修改任何其它插件。

## 为什么需要它

之前她的所有状态都是「内部的数字」——心情、耐心、体力、好感。没有一件**发生在她身上的事**。

人会说「今天下雨」「数学小测没考好」「阳台那盆月季开了」——这些事跟对面的人无关，是她自己的日子。而那时候的花花，所有输出都指向对话里的人，像一个永远在等指令的客服。

这个插件就是给她一条**不围绕你转的时间线**。

## 怎么工作

**每天按时间段抽 1~2 件**

| 时段 | 内容举例 |
|---|---|
| 早上 | 起晚了差点没赶上第一节课 / 阳台那盆月季今早开了一朵 |
| 中午 | 食堂排了很久的队 / 数学小测比估的分高两分 |
| 下午 | 体育课跑了两圈腿有点软 / 画了半张速写手一直抖 |
| 晚上 | 在阳台坐了一会儿风挺凉 / 打了会儿游戏输得挺惨 |
| 夜里 | 有点困了但还不想睡 / 翻了几页书走神了 |
| 全天 | 今天降温了手指有点僵 / 下了一天雨窗户一直是湿的 |

只抽「已经过去的时段」，不会出现「凌晨说下午要去上体育课」。

**什么时候提**

- 每轮有 15% 概率（可调），且两次之间至少隔 60 分钟（可调）
- 对方问「在干嘛」「今天怎么样」「忙什么」→ **必定想起来**
- 每件事只提一次，提过就打勾

注入的样子：

```
【你今天的一件小事（你自己的日子，不是对方的事）】
下午画了半张速写，手一直抖
如果对方问起、或者话题正好合适，可以顺口提一句；不提也完全没关系，别硬塞。
```

关键在于最后那句——不逼她说。有的话她只是自己知道。

## 面板

手账风格：右侧大日期水印、时间轴竖排、状态是一枚「已提／未提」的印章。可以：

- **换一批**：今天的不喜欢就重抽
- **添一件**：自己写一条今天的
- **标记已提**：手动打勾
- 下面是一周的流水账（提过的正常显示，没提的用淡色）

## 命令

| 命令 | 作用 |
|---|---|
| `/今天` | 看今天的事和状态 |
| `/今天 换` | 换一批 |
| `/今天 加 阳台的风很大` | 添一件 |

## 接口

| 路径 | 说明 |
|---|---|
| `GET /today` | 今天的 + 最近七天 |
| `POST /reroll` | 换一批 |
| `POST /add` | 添一件 |
| `POST /said` | 标记已提 |

## 数据

`data/plugin_data/astrbot_plugin_today/today.json`，只保留最近 14 天，删掉即可重建。

## 和别的插件怎么分工

| 插件 | 管什么 |
|---|---|
| 她自己的今天（本插件） | 她今天发生了什么 |
| 她自己的情绪 | 她心情怎么样 |
| 她自己的小回忆 | 她和谁发生过什么 |
| livelystate | 身体状态 |
